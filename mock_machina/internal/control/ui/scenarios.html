Without the dashboard

One request only, leaving the server as it is:

curl -H 'X-Mock-Scenario: {{$.Example}}' http://{{$.Host}}/…

For the whole mock, from a test or script:

curl -X POST http://{{$.Host}}/__mockmachina/scenarios/{{$.Example}}/apply

Applying removes every pin first. Reset forgets the scenario.
