# Tiny Tools
This Repository consists mono-repos of tiny tools and concepts my mind wonders about and decide to build, If i the project ever becomes too large it would be moved to separate repositories to managed

## Current Tools

- Rodinia: A simple key-value store that flutter package, with encryption and time-based expiration, WAL, compaction, and stream of events. Built with Rust FFI and Flutter.

- [MockMachina](mock_machina/README.md): mock APIs served from contract files in your repository, with switchable states for success, empty and error screens. In development (Phase 0).
